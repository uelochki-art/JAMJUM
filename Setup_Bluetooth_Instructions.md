# Инструкция по беспроводному подключению JAMJUM JP-MINI по Bluetooth

Ваш контроллер **JAMJUM JP-MINI** использует стандарт **Bluetooth Low Energy (BLE) MIDI**.
В Windows для трансляции BLE MIDI в любые музыкальные программы используется стандартный и надёжный мост: **MIDIberry + loopMIDI**. Все необходимые установочные файлы уже лежат у вас в папке `C:\Distr\Tools for Windows BLE MIDI`.

---

## Шаг 1: Подключение JP-MINI в Windows по Bluetooth
1. Включите контроллер JP-MINI (кнопка питания/переключатель на корпусе, должен замигать индикатор Bluetooth).
2. На компьютере откройте: **Параметры Windows** $\rightarrow$ **Bluetooth и устройства** $\rightarrow$ **Добавить устройство** $\rightarrow$ **Bluetooth**.
3. Найдите в списке устройств **JP-Mini** (или **MIDI-01** / **P-16**) и нажмите **Подключить**.
4. Windows подтвердит сопряжение.

---

## Шаг 2: Установка виртуального кабеля loopMIDI
1. Перейдите в папку `C:\Distr\Tools for Windows BLE MIDI` и запустите `loopMIDISetup.exe`.
2. Пройдите стандартные шаги установки (Next $\rightarrow$ Install).
3. Запустите программу **loopMIDI** из меню «Пуск».
4. В поле **New port-name** оставьте стандартное имя `loopMIDI Port` и нажмите кнопку с плюсом **`+`** внизу слева.
5. Порт появится в списке. Программу loopMIDI можно свернуть (она остаётся активной в трее рядом с часами).

---

## Шаг 3: Установка и настройка MIDIberry
1. В папке `C:\Distr\Tools for Windows BLE MIDI` запустите `MIDIberry Installer.exe` и завершите установку.
2. Запустите **MIDIberry** из меню «Пуск».
3. В левой колонке (**INPUT**) кликните по вашему контроллеру: **JP-Mini** (или **MIDI-01**).
4. В правой колонке (**OUTPUT**) выберите виртуальный порт: **loopMIDI Port**.
5. Теперь при ударе по любому физическому пэду в окне MIDIberry будут бежать логи сообщений!

---

## Шаг 4: Запуск Gussy Pad Launcher
1. Запустите `Run_Gussy_Pad_Launcher.bat` (или файл `main.py`).
2. В верхнем правом углу появится зелёный значок: `● Подключено: loopMIDI Port 0`.
3. Готово! Теперь вы можете нажимать пэды, переключать пресеты 1 и 2, регулировать громкость и сворачивать окно в трей.
